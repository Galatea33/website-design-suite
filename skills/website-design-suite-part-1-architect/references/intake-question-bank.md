# Adaptive Intake Question Bank

Use only the questions that change the design. Ask three to five initial questions in Guided mode and no more than three conditional follow-ups. Prefer one batch and recommended defaults.

## Core questions

### Purpose and action

> What should this page accomplish first: start a trial, sell, book a call, download, contact, showcase work, explain a product, or something else?

Capture the audience and the single action that should receive the strongest visual priority.

### Scope

> What are we making: a locked single-screen hero, a scrolling landing page, a multi-page marketing site, a portfolio, or an application surface?

Recommended default for an undefined marketing request: a focused scrolling landing page.

### Brand and reference authority

> Which inputs are authoritative: logo, brand guide, colors, fonts, copy, assets, existing site, screenshots, or admired references? Should references be matched, adapted, or used only for mood?

Route exact matching to Part 2.

### Visual direction

> Which direction is closest: editorial, cinematic, quiet minimal, premium, playful, technical, natural, bold experimental, or another description?

Ask for one or two adjectives and one taboo. Do not make a style list into the visual thesis.

### Main visual medium

> What should create the main atmosphere: typography and color, still image, ambient video, scroll-controlled video, an interactive reveal, product demonstration, illustration, animated graphics, or 3D?

Recommended default when media is unavailable: typography and color with a stable image-ready composition.

### Finish level

> Should the first result be a design concept, a functional prototype, or a production-integrated implementation?

Ask only when the user's requested artifact is ambiguous.

## Conditional video questions

Ask only if video materially affects architecture.

1. **Behavior:** Ambient loop, fixed background, scroll-controlled timeline, click-to-play, product demo, pointer/touch reveal, multi-section sequence, or content-synchronized scenes?
2. **Source and rights:** Existing file/URL, commissioned footage, generated placeholder, stock asset, or poster-only first draft?
3. **Mobile/fallback:** Same video, lighter alternate, static poster, or no decorative media? What should happen for reduced motion, data saving, touch, keyboard, and coarse-pointer devices?

Optional follow-up when the source is unknown:

> What mood and pacing should the footage have: calm atmospheric, cinematic, energetic, product-focused, human/lifestyle, or abstract?

Do not ask users for codec, preload, CORS, frame-cache, DPR, mask implementation, or loop-fade mechanics unless they are technically responsible for those constraints. Translate design intent into the technical strategy yourself.

## Conditional content questions

Ask only when missing content would distort the draft:

- Is the copy final, draftable, or placeholder-only?
- Which proof is real and approved: customer names, testimonials, metrics, awards, security claims, or none yet?
- Which sections are mandatory?

Never fabricate proof or capabilities.

## Conditional interaction questions

Ask only when the answer changes navigation or state architecture:

- Does the main CTA navigate, open a form, start a flow, or trigger media?
- Is mobile navigation a drawer, sheet, dropdown, simplified links, or already defined?
- Which interaction must be demonstrated in the first draft?

## Compact intake example

```text
Before I draft it, I need four decisions:

1. What is the primary visitor action?
2. Do you want a single-screen hero or a scrolling landing page?
3. Which direction is closest: editorial, cinematic, quiet minimal, or playful?
4. Should the hero be typography-led, image-led, or video-led?

If you are unsure, I recommend a scrolling, typography-led first draft with subtle motion and accessible media fallbacks.
```
